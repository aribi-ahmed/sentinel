# ChromaDB Local Vector Store

This directory contains the persistent local database generated by ChromaDB for Sentinel's Retrieval-Augmented Generation (RAG) pipeline.

## Notice
This folder is intentionally **git-ignored** to prevent binary database files and platform-specific index binaries from bloating the repository.

## How to Populate
The database is automatically generated or updated when you run the vector ingestion script:

```bash
python ingest.py
